# Обновление репозиториев (калькулятор и Telegram-бот)

**Полная инструкция для Cursor и разработчиков:** см. ** [ПУШ_В_РЕПОЗИТОРИИ_ИНСТРУКЦИЯ.md](ПУШ_В_РЕПОЗИТОРИИ_ИНСТРУКЦИЯ.md)** — там по шагам без костылей: два репо, что куда пушить, какие файлы бота копировать в delivery-bot-telegram.

---

У проекта **два репозитория**:

| Репозиторий | Назначение |
|-------------|------------|
| **gerol4lfun/greenhouse-calculator** | Калькулятор (весь проект). Пушим из папки проекта. |
| **gerol4lfun/delivery-bot-telegram** | Telegram-бот для дат доставки. Деплой на Railway. Код лежит в `telegram-bot/`, но пушить нужно из **отдельного клона** этого репо, предварительно скопировав туда файлы из `telegram-bot/`. |

## Быстрые команды

**Калькулятор** (из корня проекта):
```bash
git add . && git commit -m "vXXX: описание" && git push origin main
```

**Бот** — копируем из `telegram-bot/` в клон delivery-bot-telegram, затем из папки клона:
```bash
cp путь/к/проекту/telegram-bot/{index.js,parser.js,cities.js,supabase.js,package.json} .
git add . && git commit -m "описание" && git push origin main
```

Подробности, список файлов бота и что делать, если .git неполный — в [ПУШ_В_РЕПОЗИТОРИИ_ИНСТРУКЦИЯ.md](ПУШ_В_РЕПОЗИТОРИИ_ИНСТРУКЦИЯ.md).
