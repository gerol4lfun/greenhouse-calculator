## 🔧 ПЛАН РЕАЛИЗАЦИИ

### Этап 1: Создание структуры папок
- [ ] Создать папку `image/greenhouses/`
- [ ] Создать подпапки для каждого типа теплицы
- [ ] Создать папку `details/` для деталей каркаса

### Этап 2: Копирование фотографий
- [ ] Пользователь копирует фотографии с компьютера в соответствующие папки
- [ ] Проверка всех фотографий на наличие и корректность
- [ ] Оптимизация размеров фотографий (если нужно)

### Этап 3: Создание JSON структуры данных
- [ ] Создать файл `js/greenhouses-data.js` с данными о фотографиях
- [ ] Структура:
  ```javascript
  const GREENHOUSES_DATA = {
    arochnaya: {
      name: "Арочная (Боярская)",
      description: "...",
      photos: [
        "image/greenhouses/arochnaya/main.jpg",
        "image/greenhouses/arochnaya/view_1.jpg",
        ...
      ]
    },
    ...
  }
  ```

### Этап 4: Создание модального окна для галереи
- [ ] Создать функцию `showGreenhousesGallery()` в `js/scripts.js`
- [ ] Модальное окно с:
  - Список типов теплиц (слева или сверху)
  - Галерея фотографий выбранного типа
  - Навигация по фотографиям (стрелки, счетчик)
  - Кнопка скачивания для каждой фотографии
  - Адаптивный дизайн для мобильных

### Этап 5: Замена ссылки в index.html
- [ ] Заменить ссылку на Яндекс Диск на вызов `showGreenhousesGallery()`
- [ ] Обновить текст карточки (если нужно)

### Этап 6: Интеграция с FAQ
- [ ] Обновить ссылки на фотографии в FAQ (если используются)
- [ ] Использовать новые пути к фотографиям

## ✅ ПРЕИМУЩЕСТВА

1. **Независимость от внешних сервисов** - фотографии всегда доступны
2. **Быстрая загрузка** - фотографии на том же сервере
3. **Кеширование** - фотографии кешируются браузером
4. **Удобство** - не нужно открывать внешние ссылки
5. **Контроль** - полный контроль над фотографиями
6. **Интеграция** - можно использовать фотографии в FAQ и других местах
